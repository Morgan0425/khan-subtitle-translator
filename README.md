# 可汗双语字幕

一个面向 Chrome / Edge 桌面浏览器的 Manifest V3 扩展。它读取可汗学院 YouTube 播放器中的英文 CC，在视频上叠加本地翻译后的双语字幕。

## 功能

- 默认翻译为简体中文
- 双语、仅译文、仅原文三种显示方式
- 支持简体中文、繁体中文、日语、韩语、西班牙语、法语和德语
- 自动开启 YouTube 播放器的 CC
- 使用 Chrome 138+ 的 Translator API 在设备本地翻译
- 不需要 API Key，不把字幕发送到第三方翻译服务
- 对可汗学院的 HTML5 备用播放器提供 `TextTrack` 回退支持

## 安装

1. 确认使用桌面版 Chrome 138 或更高版本。
2. 打开 `chrome://extensions/`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本文件夹 `khan-subtitle-translator`。

## 使用

1. 打开一个可汗学院视频页面。
2. 点击页面右侧的蓝黑色“译”按钮。
3. 打开“启用字幕翻译”。首次使用某种语言时，Chrome 会下载本地语言包。
4. 播放视频。扩展会自动打开英文 CC，并在视频上叠加翻译。

## 常见问题

### 一直显示“等待视频字幕”

- 先开始播放视频；YouTube 在暂停且尚未播放时通常不会产生字幕节点。
- 确认该视频有英文 CC。
- 在播放器内手动点一次 CC，再继续播放。
- 刷新可汗学院页面，然后重新打开扩展开关。

### 提示需要 Chrome 138+

Translator API 从 Chrome 138 起稳定提供，且只适用于桌面版。移动版 Chrome 目前不支持。

### 首次翻译较慢

首次使用某种语言组合时，Chrome 需要下载语言包。之后翻译在本机完成，通常会明显更快。

## 隐私与权限

扩展只申请：

- `storage`：保存开关、目标语言和显示方式。
- 可汗学院页面访问：显示控制面板和字幕。
- YouTube 嵌入播放器访问：读取屏幕上已经显示的 CC 文本。

字幕翻译由 Chrome 内置模型在设备本地执行。扩展不包含统计、广告或远程代码。

## 已知限制

- 当前针对可汗学院网页端使用的 YouTube 嵌入播放器和 HTML5 备用播放器。
- YouTube 或可汗学院若大幅修改播放器 DOM，字幕选择器可能需要更新。
- 翻译质量取决于 Chrome 的本地语言模型；数学专有名词偶尔需要人工判断。
- Chrome 之外的浏览器即使能加载 Manifest V3，也不一定实现 Translator API。
